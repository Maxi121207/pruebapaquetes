# Contributing to pruebapaquetes

Thank you for investing your time in contributing to our project! Any
contribution you make will help improve this package.

## Code of Conduct

By participating in this project, you agree to abide by our Code of
Conduct. Please read it before contributing.

## How Can I Contribute?

### Reporting Bugs

Before creating a bug report, please check the existing Issues list to
see if the problem has already been reported. If it hasn’t, open a new
issue and include: \* A clear and descriptive title. \* Steps to
reproduce the behavior. \* A minimal reproducible example (reprex) using
the `reprex` package if possible. \* Your R session information
([`sessionInfo()`](https://rdrr.io/r/utils/sessionInfo.html)).

### Suggesting Enhancements

We welcome ideas for new features or improvements. To suggest an
enhancement, please open an issue and: \* Explain the behavior or
feature you would like to see. \* Provide examples of how it would be
useful or how the syntax would look.

### Submitting Pull Requests

1.  Fork the repository and create your branch from `main`.
2.  If you’ve added code that should be tested, add tests in the
    `tests/testthat` directory.
3.  Ensure that the package passes all checks by running
    `devtools::check()`.
4.  Update the documentation if necessary using `devtools::document()`.
5.  Submit a pull request with a clear description of your changes.

## Style Guide

Please follow the tidyverse style guide (`styler` package can help
format your code automatically) for any R code contributions.
