# Suma que rechaza texto

Esta funcion suma 2 numeros y devuelve un error si alguno es texto.

## Usage

``` r
suma_string(x, y)
```

## Arguments

- x:

  Numeros positivos

- y:

  Numeros positivos

## Value

Vector con la suma de los numeros positivos

## Examples

``` r
suma_string(1, 1)
#> [1] 2
suma_string(28, 78)
#> [1] 106
```
