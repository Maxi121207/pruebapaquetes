# Suma que rechaza negativos

Esta funcion suma 2 numeros y devuelve un error si alguno es negativo.

## Usage

``` r
suma_negativos(x, y)
```

## Arguments

- x:

  Numeros positivos

- y:

  Numeros positivos

## Value

Vector con la suma de los numeros positivos

## Examples

``` r
suma_negativos(1, 1)
#> [1] 2
suma_negativos(28, 78)
#> [1] 106
```
